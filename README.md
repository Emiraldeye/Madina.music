# Madin Music — Android

Розово-чёрный музыкальный поисковик с фембой-маскотом и озвучиванием фразы по нажатию.

## Сборка APK
1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Откройте папку `MadinMusicAndroid` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Что умеет
- Поиск по названию/исполнителю через YouTube, SoundCloud, Bandcamp, Jamendo и Internet Archive.
- Режим «Все источники» открывает общий веб-поиск по музыке.
- Нажатие на маскота произносит: «Очень очень очень много мадин».
- Ссылки открываются в браузере; загрузка возможна там, где площадка и правообладатель разрешают её.

## Важно
Приложение не обходит DRM, платные подписки, авторизацию или ограничения сайтов. Оно отправляет запросы на страницы поиска выбранных площадок, а не извлекает аудиофайлы скрытым способом.
